# Workshop: Overleef de crash

Load balancing met HAProxy en 3 webservers, in docker compose.

- `track-a/` : leeg, ervaren studenten bouwen alles zelf
- `track-b/` : starterpakket met TODO's
- `oplossing/` : werkende versie (push deze pas tijdens de workshop)

Starten (in track-b of oplossing):

    docker compose up -d

Website op poort 80, HAProxy statspagina op poort 8404.
